# 隐私与数据说明

Alpha 默认将设置、待办、日程、笔记、剪贴板历史、连接元数据和诊断日志保存在 `%APPDATA%\Alpha`。`DESKTOP_ISLAND_DATA_DIR` 可覆盖目录。整个数据目录均不适合公开上传。

- DeepSeek 密钥和邮箱/日历凭据使用 Windows 凭据管理器；部分独立登录凭据使用当前 Windows 用户的 DPAPI 加密。
- 账号元数据可能包含邮箱地址、显示名称和本机路径，不能因为没有密码就视为适合公开。
- 翻译会将输入文字发送给 DeepSeek；图片先在 Windows 本地 OCR，再发送识别文字。点击翻译/快捷键或相应粘贴操作可能触发请求；切换栏目不会自动上传剪贴板。
- 邮箱、日历、AI 额度、封面和歌词功能在启用/使用后会访问对应第三方服务；第三方隐私政策和资费仍适用。
- 音乐兼容功能可能读取本机播放器缓存和播放元数据；仅用于本机展示，不上传完整播放器日志或音频。
- AI 任务 Hooks 记录客户端、会话、项目路径、时间与状态，不记录提示词或聊天正文。用户须自行审核 Hook 命令。
- Bot 接入与 AI 建议已移除，程序不再发布共享快照或接收 Bot 建议。
- 未接入项目自建的统一云端账号或数据汇总服务；诊断日志不自动上传。
- 上游自动更新已禁用，请从本项目源码手动更新。

本开源仓库仅发布源码、公共资源和合成测试数据，不发布作者的实际账号配置或历史开发日志。请勿提交真实密钥、Cookie、授权码、登录 JSON、邮件、笔记、剪贴板历史或内存转储。
